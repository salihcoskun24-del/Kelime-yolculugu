KELİME YOLCULUĞU 2.1
====================
6 dil: İngilizce, Almanca, İspanyolca, Rusça, Arapça, Fransızca.
Her dil: 100 bölüm ve 1000 kelime/ifade; Türkçe karşılıklarla eşleştirme.

Açılışta bir dil seç. Dil düğmesinden istediğin zaman değiştir.
Her dilin ilerlemesi, devam eden bölümü ve hakları ayrı saklanır.
Yeni dillerin listeleri kolaydan zora; eski İngilizce sırası kaydı korur.
Sıralı CSV kelime listeleri kelime-listeleri klasöründedir.

OYUN
Yabancı dilde kelimeye dokununca o dilde sesli okunur.
Türkçe karşılığını seç. 10 doğru eşleşmeden sonra o bölümden üç kelimeyle cümle soruları açılır.
Üçünü de doğru yanıtlayıp Bölümü tamamla deyince sonraki bölüm açılır.
Yanlış cümle cevabında yalnızca o soruyu tekrar denersin.
Türkçe anlamlar ve üç cevap seçeneği vardır. Dolu cümleyi dinleyebilirsin.
Yanlış eşleşmede bölüm yeniden başlar. Kaldığın eşleşmeler kaydedilir.
Kelime defteri tamamladığın bölümleri gösterir; orada da telaffuz dinlenir.

YARDIMCILAR — HER DİLDE 5 + 5 HAK
Kaldığım yere gel: Yanlış cevapla sıfırlanan bölümde önceki doğru çiftleri
1 hak karşılığında geri getirir. 8 doğru sonrası yanlışta 0/10 olur;
düğmeye basınca 8/10 geri gelir, 1 hak düşer. Sayfa yenilense de kurtarma
kaydı saklanır. Geri getirilecek çift yoksa hak harcanmaz.
Aynı kurtarma kaydı bir kez kullanılabilir. Haritadan da geri getirilebilir.
İpucu: Eşleştirmede doğru çifti, cümlede doğru seçeneği işaretler.
Eşleştirmeyi veya cümle cevabını sen seçersin.
İpucu görünürken tekrar dokunmak ikinci hak harcamaz.
Haklar kayıtlı kalır, bölüm geçince veya sıfırlayınca yenilenmez.
Bakiye sıfırsa yardımcı pasif olur. Reklamla hak kazanma henüz eklenmedi.
Normal devam düğmesi ve bölümleri elle seçmek ücretsizdir.

HEMEN ÇALIŞTIR
ZIP'i çıkar. Python 3 olan bilgisayarda BASLAT_WINDOWS.bat'ı aç
veya terminalde python calistir.py (Mac/Linux: python3 calistir.py) çalıştır.
http://localhost:8080 adresini aç.
Telefon aynı Wi-Fi ağındaysa terminalde yazan yerel IP adresini aç.
Yerel ağ güvenlik duvarı izni gerekebilir. Bilgisayar açık kalmalıdır.
index.html'i çift tıklamak yerine sunucuyu kullan.

VERCEL'DE YAYINLA
Vercel > Add New > Project > GitHub deposunu içe aktar.
Root Directory depo kökü, Framework Other. www klasörünü kök seçme.
vercel.json build ve çıktı ayarlarını tanımlar: npm run build, çıktı dist.
Deploy seç. Ortam değişkeni veya API anahtarı gerekmez.
Mevcut projede otomatik dağıtım başlamazsa Redeploy seç.

TELEFONA YÜKLE
HTTPS ile yayınlanmış adresi telefonda aç.
Android Chrome > Menü > Uygulamayı yükle / Ana ekrana ekle.
iPhone Safari > Paylaş > Ana Ekrana Ekle.
İlk açılış internet ister. Dosyalar önbelleğe alınınca tüm dillerde
oyun çevrimdışı çalışır. Yerel HTTP telefon adresi çevrimdışı kurulum sunmaz.
Telaffuz cihazın dil ses paketini kullanır; gerekirse ilgili sesi indir.
Ses kalitesi ve çevrimdışı telaffuz desteği cihaza/tarayıcıya bağlıdır.
Bu paket hazır APK veya IPA değildir.

ANDROID APK
Node.js 22+, JDK 21, Android Studio ve SDK kurulu bilgisayarda:
npm install
npm run android:add
npm run android:sync
npm run android:open
Android Studio'da APK üret. Bu ortamda yerel APK derlenmedi.

KAYITLAR
Eski İngilizce kaydı otomatik taşınır.
Ayarlar > Tüm dilleri yedekle ile JSON indir; başka cihazda geri yükle.
Tarayıcı verisini silmek kaydı siler. Canlı adres değişirse kayıt taşınmaz;
önce yedek al. İlerleme otomatik eşitlenmez.
İlerleme sıfırlama yalnızca seçili dili etkiler ve hakları yenilemez.

TEKNİK
npm run check: altı dilin 6000 kaydını ve JavaScript'i doğrular.
npm run build: Vercel için dist klasörünü üretir.
npm run vocabulary:export: CSV listelerini yeniden üretir.
Veri hazırlığı ve sıralama: VOCABULARY.md.
3D etkiler SVG/CSS ile sağlanır. Orijinal Python original klasöründedir.

CÜMLE VERİLERİ
Her dilde 100 bölüm x 3 soru, toplam 1800 cümle sorusu.
Cümleler ve cevaplar cumle-sorulari klasöründeki CSV listelerinde.
Cümle aşaması ve geri getirilebilir eşleşmeler yedeklere de dahil edilir.
